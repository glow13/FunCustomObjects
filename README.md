# Fun Custom Objects

### ***Play with some fun custom objects in Geometry Dash!***

This mod adds some example custom objects created with my mod [Custom Objects API](https://github.com/glow13/CustomObjectsAPI)!

None of these objects are actually useful, this was simply made to test my API and to be a reference for developers who want to add their own custom objects!

This mod will never be submitted to the index, but feel free to download it from the [release tab](https://github.com/glow13/FunCustomObjects/releases) and try the custom objects out yourself!
